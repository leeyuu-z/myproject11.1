# 年度面板设计及最低可行性门槛

观察单位为银行实体×年度，唯一键bank_id+year。采用非平衡面板亦可，不为凑平衡而补造值。候选2010—2021，最终取同版本数字化指数与财务真实覆盖的交集。

样本待确认：建议先评估“境内A股上市商业银行，银行上市后年度进入”的口径；上市当年是否纳入由导师确认。备选为截至2021年末上市银行并回溯历史，但须披露上市前观测及存续选择偏差。H股是否纳入另行确认，不擅自定稿。

匹配顺序：保留原始名/代码→核验证券基本信息→建立实体稳定ID→按经审核的精确别名或证券代码+交易所匹配。代码一律字符串保留前导零。A/H两地上市只对应一个银行实体，不能重复计数。更名须有生效期证据；合并重组不得只按相似名称视为同一实体；禁止自动模糊合并。未匹配值输出待审核表。

跨表先确定年末、币种、报表类型、重述版本、监管统计口径，再去重。重复银行年度必须解释原因并明确选取规则；不能随意取第一条。分别记录原值、原单位、标准值和换算依据。

最低核查：
- 两个核心来源真实取得且有合法研究权限和指标说明。
- 指数、CIR、总资产与银行映射有实际交集，年度键唯一、核心值有效、单位可解释、缺失分布可报告。
- 固定效应需要多个银行和多个年份，Digital在扣除银行与年份效应后仍有剩余变异；不能仅凭“有两家两年”称推断可靠。
- 没有通用最低银行数。需报告实际银行数/年数/观测数、缺失与筛选损失、聚类数、组内变异和有效自由度，再与导师判断本科论文是否足够；少数聚类时推断受限。
- 不用行业汇总、省市数字普惠金融指数代替银行级指数；不以插值填补核心指数。
