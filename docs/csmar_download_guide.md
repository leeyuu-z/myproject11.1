# CSMAR人工导出指南

当前未登录，也未确认湖南工商大学的具体订阅。以下为按指标关键词寻找的路径，不是已核实的菜单截图或表代码。

1. 从学校图书馆数据库导航进入CSMAR；按图书馆要求使用校园网络、学校授权远程访问及个人账号。不向聊天提供密码；若无银行子库权限，咨询图书馆。
2. 在数据库检索中查找“银行”“银行财务”“中国银行财务研究数据库”等关键词。优先检查银行专用财务指标；若名称变化，以授权页面实际名称为准。记录数据库全名、表名、字段中文名/实际代码、定义、更新时间。
3. 候选筛选2010—2021年、年度、报告期12月31日、商业银行；优先合并报表，标记监管指标自身口径。上市范围待导师确认；可先导出较宽的合法范围，再按证券基本信息筛选，不能默认246家均上市。
4. 首批导出：银行名称/银行标识、证券代码及交易所、报告期、成本收入比、总资产、原单位/币种/报表类型。第二批补资本充足率、不良贷款率、ROA。另导出证券简称、法定名称、上市日期、退市日期及更名信息。总资产可在上市公司资产负债表找；CIR、CAR、NPL优先银行专用子库，避免普通企业同名指标。
5. 下载CSV（注明编码）或XLSX，连同字段说明及筛选条件保存至data/raw/csmar/；不要手工修改原始文件。记录下载日、范围、年度口径、单位、是否最新重述、缺失码。运行盘点脚本，再核验数家银行年报中的同年度指标。

导出批次记录表：数据库实际名、表名、导出条件、字段名/代码、单位、口径、数据版本、导出时间、原文件名、授权限制。不能确认字段含义时保留待核实，不用相似名字替代。

补录年报：每值记录银行ID、年度、字段、原数值、原单位、报告名称、官方URL、PDF页码及印刷页码/表名、口径、提取日期、复核人；手工补录单独文件，不覆盖CSMAR原数据。
