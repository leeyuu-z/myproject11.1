# 无CSMAR授权时的财务数据备选方案

状态：方案待小范围真实试采；未下载数据，不能报告成功率或样本量。北大指数仍待回复，不擅自改变核心解释变量。

## 先试采，再确定规模

从拟研究范围内选择少数银行，分别覆盖拟比较的银行类型，在官方投资者关系网站寻找同一年度及较早年度年报，检查成本收入比、总资产、口径和单位是否可追溯。试采银行与年度须登记，不把试采范围当正式样本。不先承诺手工覆盖2010—2021全部上市银行。

优先寻找年报中的“主要财务指标”“成本收入比”“资产负债表”“资本充足率”；PDF全文搜索只用于定位，最终按表头、脚注及页码核对。优先明确披露的CIR，不自行用费用/收入重算来冒充披露指标。集团与母公司口径、不同监管指标口径不能默默混合。未披露时保留缺失与原因。

首批最低字段：银行名称、年度、披露的成本收入比、年末总资产；另记录证券代码、交易所、上市时间用于样本筛选。资本充足率为可选补充，不良贷款率和ROA暂不扩大采集负担。原始单位先保留，审核后统一换算。

每个提取值记录官方URL、报告标题、报告年度、页码（PDF与印刷页码分别记）、表名、原值、原单位、报表口径、提取日期及复核状态；保存原始PDF及SHA256。无法确定的数值标待核验，不猜测、不插值。

## 指数申请未回复时

保留首次发送日期与邮件记录，先在官方页面核验收件地址。若已等待约7—10个工作日，可考虑在原邮件线程礼貌跟进一次；该时间是沟通建议，不是课题组官方承诺。不要发送账号密码或身份证明敏感材料到未核实地址。本项目不会代发邮件。

若持续无法取得指数：请导师决定继续等待、采用另一项合法且有清楚定义与银行年度覆盖的既有银行数字化指标，或调整题目。自行构建年报关键词指数涉及词典、语料和有效性验证，会改变测量方法与工作量；不作为已授权的默认替代方案。
