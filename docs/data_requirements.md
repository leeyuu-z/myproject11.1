# 数据需求与变量字典

最小必要：bank_id/bank_name、year、digital、cir、total_assets。所有字段目前缺少真实观测。下述标准字段是本项目设计，不是CSMAR实际字段代码。

|标准字段|含义/单位|优先来源与口径|预处理/作用|
|---|---|---|---|
|bank_id|银行实体稳定字符串ID|人工审核映射表|不可直接用可变简称；面板实体键|
|bank_name|银行法定名称|指数原文件、CSMAR、年报|原名保留，审核别名匹配|
|year|年度整数|指数年度/财务报告期|财务限12月31日；不混季报|
|digital|总数字化指数，单位以官方说明为准|北大银行数字化转型指数同一期|保留原值、子维度及版本；核心解释变量|
|cir|成本收入比，统一为百分数数值|银行披露/银行专用CSMAR指标|保留原单位；0—1到百分数转换须元数据支持；因变量，越低通常效率越高|
|total_assets|总资产，统一人民币元|CSMAR合并资产负债表年末值|保留原币种及单位，正值才能取对数；规模控制|
|ln_assets|总资产自然对数|由统一口径total_assets计算|不得对不同货币或单位直接混算|
|car（可选）|资本充足率，百分数|银行专用监管指标|不是核心一级资本充足率；记录监管定义变化|
|npl（可选）|不良贷款率，百分数|银行专用指标|不是不良贷款余额；加入模型前讨论中介/内生性|
|roa（可选）|总资产收益率，百分数|银行指标/年报|区分平均资产与期末资产分母；替代因变量时不再作控制|
|bank_type（可选）|银行类型分类|经核验的官方分类|记录分类日期；待导师确认分组|
|security_code、exchange|证券代码字符串及交易所|CSMAR证券基本信息|保留前导零；A/H代码不能单独当银行ID|
|listing_date、delisting_date|上市/退市日期|证券基本信息及官方上市资料|用于执行待确认的样本边界|
|report_date、statement_scope|报告期、合并/母公司口径|导出元数据|集团财务指标与银行法人监管指标差异单独标注|
|source_file、source_sheet、source_row、unit_original、source_url|来源审计字段|每个原始文件/手工记录|可以追溯原值及转换，不填造来源|

银行披露CIR是成本控制效率代理，不等于完整技术效率。不可拿普通企业成本费用率替代。研究期间2010—2021仅为候选，不能推定2022年后可用。禁止在元数据不足时自动缩放、插值或填补核心指数。
